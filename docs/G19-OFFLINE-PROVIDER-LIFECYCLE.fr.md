# G19 — Cycle de vie **simulé** des cinq adaptateurs

Cette extension est un banc d'essai hors ligne basé sur #82. Les identifiants sont uniquement des références opaques de fixture (`providerID`, `accountRef`, `sessionID`, `tabID`, `turnID`). **Aucun mot de passe, cookie, jeton, navigation, appel réseau ou déblocage du `ProviderGate`.** Le statut `ready` du compte simulé n'est **jamais** une autorisation d'automatisation : `assessAdapter` conserve sa politique restrictive pour ChatGPT, DeepSeek, Gemini, Qwen et Mistral Vibe.

`beginManualLogin` enregistre une intention humaine explicite, efface les signaux anciens tout en gardant leurs révisions ; `confirmManualLogin` nécessite une nouvelle observation de connexion non contredite par un blocage. Les simulations historiques d'observation de #82 restent disponibles sans demande de connexion. `beginReconnect` n'accepte que les blocages non terminaux (déconnexion, challenge, limite) et ne restaure jamais un tour en cours ; une expiration ou déconnexion explicite révoque définitivement le bail et impose une nouvelle prise de possession.

Les diagnostics de tour contiennent exclusivement phase, séquence, longueur d'aperçu, indicateur de fin, code de santé, catégorie d'erreur et statut de revue. Ils n'exposent **jamais** les textes partiels ou finaux. `checkpoint` exporte seulement la propriété et les IDs/séquences des tours ; `recover` vérifie l'identité exacte et traite **tous** les tours récupérés comme `uncertain`, y compris précédemment achevés. Une revue opérateur avec référence opaque peut annoter un tour incertain mais ne crée pas de réponse finale, ne débloque pas son identifiant et ne prouve pas la réalité de l'effet. Aucun renvoi ni replay automatique.

Tests RED→GREEN : matrice des cinq fournisseurs, confirmation manuelle, défis, déconnexion/reconnexion, résiliation, propriété, consentement, abort en attente, flux non final, contrôle de séquence, état incertain après redémarrage, snapshot falsifié, revue répétée, taxonomie et absence de fuite. `npm run typecheck`, `npm test`, `npm run check:backlog`. Le code reste uniquement une fixture, **non prêt pour l'exploitation de comptes réels**.
